# Debug Files

Debug Files provides workspace-independent inspection of available runtime diagnostic files.

## Functional Requirements

### WS-FUNC-DEBUG-FILES-001 - Runtime Debug File Inspection

Traceability: [`WS-FUNC-DEBUG-FILES-001`](../SPEC_TRACE.md#ws-func-debug-files-001---runtime-debug-file-inspection)

The Debug Files page lists available debug files in the distribution root and loads the selected file content into an inspection panel.

## UX Requirements

### WS-UX-DEBUG-FILES-001 - Debug File Inspection View

Traceability: [`WS-UX-DEBUG-FILES-001`](../SPEC_TRACE.md#ws-ux-debug-files-001---debug-file-inspection-view)

The debug file list scrolls internally, selected file content scrolls internally, and an explicit empty state is shown when no debug files exist.
