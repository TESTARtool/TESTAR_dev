# WebStudio Capability Specifications

Each file owns the functional requirements, UX requirements, and acceptance scenarios for one WebStudio capability.

- [Foundations](./foundations.md): roles, navigation, shared editors, layout, and accessibility
- [Configuration Guard](./configuration-guard.md): dirty state, save enablement, and guarded navigation
- [Workspace Management](./workspace-management.md): workspace selection, creation, cloning, and rename
- [Test Settings](./settings.md): visual and raw `test.settings` editing
- [Composition Flow and Policies](./composition-and-policies.md): composition and Java policy editing
- [Test Oracles](./test-oracles.md): oracle configuration, Java oracles, and Rascal DSL editing
- [Runtime Modes](./runtime-modes.md): Generate, Spy, and CLI execution
- [Test Goals](./test-goals.md): workspace-scoped test goal authoring and CLI integration
- [Test Results](./test-results.md): workspace-scoped reports, summaries, filters, and deletion
- [State Model](./state-model.md): state model analysis lifecycle
- [Debug Files](./debug-files.md): runtime debug-file inspection

Requirement IDs link to the central [specification trace](../SPEC_TRACE.md). Contribution and verification rules are defined in [CONTRIBUTING.md](../CONTRIBUTING.md).
