# State Model Documentation

The `statemodel` module records abstract and concrete states, actions, and test sequences in a configured datastore. It also provides live analysis and portable model snapshots.

- [State model inference, analysis, and static export](./state-model.md): configuration, lifecycle, output layout, and acceptance scenarios.
- [State-model JSON exports](./json-export.md): configurable Abstract, Hybrid, Concrete, and Sequence Traces downloads, optional artifacts, property selection, and acceptance scenarios.
- [State identity](../core/state-identity.md) and [action identity](../core/action-identity.md): the IDs stored in the model.
- [WebStudio State Model](../webstudio/specs/state-model.md): workspace selection and live analysis controls.

Capability documents describe behavior and link acceptance scenarios to their verifying test classes. Architecture documents describe module ownership and runtime integration.
